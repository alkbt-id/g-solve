# G · READ

Задачи го на счёт; сложность подстраивается под твой ранг. Страница целиком работает в браузере, ранг
хранится только в нём.

Задачи — [Go Game Guru Weekly Go Problems](https://github.com/gogameguru/go-problems) (David Ormerod,
An Younggil), лицензия [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Изменения:
деревья ответов переведены в свой формат (`problems/ggg.json`), к задачам добавлена сложность в рангах по
модели KataGo, подражающей людям. Файл `problems/ggg.json` распространяется на тех же условиях.

Собрано `npm run build:pages` из проекта read; здесь только готовая страница.
